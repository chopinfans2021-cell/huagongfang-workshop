# 化学工坊 · 第一天重建包

这不是 Grok Build 工作区的原始导出。是按对话里**最后一版已实现逻辑**重建的可玩包，方便你本地审查、改代码、发给朋友。

## 给朋友玩

1. 打开：https://github.com/chopinfans2021-cell/huagongfang-workshop
2. 绿色 `Code` → `Download ZIP`
3. 解压后双击 `index.html`
4. 或把这个仓库开 GitHub Pages，朋友用浏览器打开即可

源码仓库：https://github.com/chopinfans2021-cell/huagongfang-workshop

## 这一天怎么玩

- 买试剂级原料
- 做一炉 T1（熟化 / 滴定 / 氯化钙 / 置换铜 / 双氧水）
- 故意选错一次，三秒内抢救
- 卖掉或交酸酸钠合同
- 点「结束今天」

存档写在本机 `localStorage` 键 `huagongfang-save-v1`，不上云。

T2–T4 和 canvas 夜班引擎没有进这个包。
